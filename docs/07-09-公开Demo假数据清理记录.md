# 07-09 公开 Demo 假数据清理记录

## 背景
用户让继续做非图标任务。图标素材等待用户明天回传，因此本批继续清理公开 Demo 中非图标的假数据/私称残留。

## 本批发现

### 1. MinePage 仍残留示例家庭名
- `MinePage` Hero 中仍显示：`本机家庭 · 小夏 + 阿川`
- 这属于私称/示例成员，不适合公开 Demo。

### 2. MinePage 仍残留默认示例菜和做饭日志
- 无真实做饭记录时仍展示默认三道菜：
  - 西兰花鸡胸肉炒蛋
  - 番茄豆腐虾仁汤
  - 芦笋虾仁炒口蘑
- 同时默认日志里有“阿川觉得更入味”等私称文本。
- 这会误导用户，以为系统已经有真实家庭做饭记录。

### 3. PlanPage Hero 仍残留示例成员名
- `PlanPage` Hero 中仍显示：`今晚 · 小夏 + 阿川`

## 本批修复

### 1. MinePage Hero 去私称
- `本机家庭 · 小夏 + 阿川` → `本机家庭`

### 2. MinePage 我家菜品改真实空状态
- 删除默认 `defaultDishes` 示例菜逻辑。
- 没有真实做饭记录时显示：
  - “还没有做过的菜。去计划页标记‘做完了’后，这里会沉淀你的我家菜品。”
  - 按钮：`去计划页`
- 有真实做饭记录时才显示做过的菜。
- `我家版` 标签只在存在 `myDishVersions` 时显示。
- 没有我家备注时显示“还没有记录我家调整”，不再编造口味调整。

### 3. MinePage 做饭记录改真实空状态
- 删除默认 `default-log` 示例日志。
- 没有真实做饭日志时显示：
  - “还没有做饭记录。完成计划后点‘做完了’，饭团会把记录和米粒奖励放在这里。”
  - 按钮：`去计划页`

### 4. PlanPage Hero 去私称
- `今晚 · 小夏 + 阿川` → `今晚计划`

## 验证

### 命令验证

- `npm run build`：通过

### 浏览器验证

- `/plan`：Hero 显示 `今晚计划`，无“小夏/阿川”私称。
- Browser console：0 JS errors。
