# 饭搭子｜家庭使用与更新

## 官方线上版（推荐）

家庭创建者与搭子都使用同一个官方网址：<https://fandazi-web-tool.vercel.app>。

- 创建者在“同步”页分享网址和家庭邀请码。
- 搭子只需首次注册/登录并输入邀请码；之后始终使用原网址，不需要下载代码、部署或重复加入家庭。
- 官方版本发布后，已打开的应用会在重新回到前台、重新打开或最长一小时内检查新版本，并自动刷新到新版本。
- 家庭数据按 `household_id` 保存在家庭云端；更新网页或重新安装 PWA 不会删除已加入家庭、冰箱、计划或购物清单。

## Mac 图标被删除

删除 PWA 图标只会移除 Mac 上的快捷入口，不会删除家庭数据。

1. 用 Safari 或 Chrome 打开官方网址。
2. 重新选择“添加到程序坞”或“安装应用”。
3. 打开恢复后的饭搭子，使用原账号登录；家庭会自动恢复。

若页面明显停留在旧版，先完全退出饭搭子后重新打开；仍无变化时，在浏览器中强制刷新一次。

## 高级自部署版

只有需要自行维护代码和后端的用户才使用自部署版。家庭成员不应各自部署；他们仍只使用该家庭创建者分享的网址和邀请码。

自部署的 fork 不会天然跟随官方仓库。仓库提供 `.github/workflows/upstream-fast-forward.yml`：当 fork 的 `main` 没有自行改动时，它会每天快进同步官方 `main`，由 Vercel 自动部署；一旦 fork 有分叉，工作流安全停止，不覆盖自定义代码或数据。
