# 07-09 图标提示词中文化修正记录

## 背景
用户反馈：图标生成提示词需要全中文，不要出现“热气”一类的词语。

## 本次修正

### 1. 提示词全中文
- 将 `docs/图标生成提示词清单.md` 中 109 个图标生成提示词全部改为中文。
- 全局风格基线也改为中文表达。
- 技术规格中的英文背景说明也改为中文。

### 2. 背景统一为透明
- 保持上一轮确认的要求：所有图标均为透明背景。
- 文档中统一写法为：
  - 透明背景
  - 不要文字
  - 不要阴影
  - 不要边框
  - 不要底色
  - 不要圆形底

### 3. 移除“热气”类描述
- 删除/避免以下词语与概念：
  - 热气
  - 冒烟
  - 烟雾
  - 蒸汽
  - steam / smoke / rising 等英文同义残留
- 对涉及汤、锅、煎蛋、热菜等提示词，改为只描述主体，不再要求任何热气、蒸汽、烟雾效果。
